## 附：这类答案在面试里的用法

| 问题类型 | 可引用的 ADR |
| --- | --- |
| "你为什么选这个技术栈" | D1 |
| "你怎么决定不做什么" | D2（范围取舍） |
| "你的项目有什么取舍" | D3（能力 vs 可测性） |
| "成本怎么控制" | D4（上下文预算 + cache） |
| "安全怎么保证" | D5 + D6（边界声明） |

**D2 和 D6 尤其值得写扎实**——「主动说不做什么，并说清代价」是区分
"做过项目"和"想过设计"的分界线。
