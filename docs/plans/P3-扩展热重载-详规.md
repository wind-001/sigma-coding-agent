# P3-扩展热重载 详规

> 版本:v1(拍板代行) ｜ 2026-09-29
> 授权:星辰全权委托续作;范围依据 D3(拍板:"热重载范围限定在工具注册表+钩子注册表,
> 不做任意代码自改写")与 architecture §4.4(三个失败场景必须单测)。
> 现状:registry.py 只有约束注释,**reload_source 未实现**——P4 验收门"改扩展文件
> 后当轮生效"是路线图最后一项未落地的功能。

## 1. 范围与不做

**做**:工具级热重载——`extensions/*.py` 里的工具文件改完后,REPL `/reload`
触发 `ToolRegistry.reload_source()`,**当轮生效**;钩子注册表的重载留待有真实
扩展需求时再做(D3 是范围**上限**不是承诺清单,不做没有消费者的机制)。

**不做**:任意代码自改写(agent 改 harness 自己的代码)、钩子热重载、
扩展的依赖管理、卸载语言的沙箱(扩展代码以用户权限执行,与 bash 同一边界,
写进 extensions/README)。

## 2. 机制

**扩展文件约定**(零框架):每个 `extensions/<name>.py` 在模块级定义
`TOOLS: list[BaseTool]`——实例即注册项,`source="extensions/<name>.py"`。
没有 TOOLS 导出 = 空注册(场景 2)。

**导入必须新鲜**(架构 4.4 的代码契约):`importlib.util.spec_from_file_location`
+ 每次生成 uuid 模块名 + `sys.modules` 注册——**不用 importlib.reload**(旧引用
不更新,那是"改了代码但行为没变"的头号来源)。

**reload_source(source) 五步,失败不进半更新状态**:
1. `_import_fresh(path)`;导入异常 → **保留旧表**,返回失败报告(场景 1);
2. 校验 `TOOLS` 是 BaseTool 实例列表;缺失/为空 → 清理该 source 旧注册项,
   视为"扩展已移除"(场景 2);
3. 重名检查:与内置**或与其他扩展**重名 → `DuplicateToolError`,拒绝本次,
   保留旧表(场景 3,与"不允许静默覆盖内置"同一条纪律);
4. 全部通过才原子替换该 source 的注册项(`_tools`/`_source_of` 一次改完);
5. 返回 `ReloadReport(added/removed/failed_reason)`。

**调用方零缓存**(已有约束的运行期验证):`get()` 每次查表,热重载后立刻拿到
新实例——G-HR-5 用"替换实现后 get() 结果变化"证明。

## 3. 与 D4 的冲突:常驻区重建(本详规的核心设计点)

工具 schema 进常驻区、会话内逐字节稳定(指纹断言 G26)——**热重载必然改变
schema**,在会话中直接替换注册表会让 `verify_resident_region` 当场炸。
这不是bug,是两主张的真实张力,处置:

- **会话内热重载 = 显式违约点**:用户敲 `/reload` 就是"我知道缓存要失效"的
  意思。实现上由 `InteractiveSession.reload_tools()` 走完整重建路径:
  `registry.reload_source()` → 用同一套参数(system_prompt/_instructions/
  skill_index/memory_index/repo_map/tree)**重建 SessionContext**(指纹以
  新 schema 重算;历史与压缩视图原样保留;SessionPersistHook/TraceHook 重新
  挂到新 context——trace 用新文件路径会丢会话连续性,**persist 钩子重建,
  trace 保持原路径**);
- 提示词工具行**不含扩展工具**(扩展没有提示词行,它们是运行时注册的),
  所以 `system_prompt` 字节不变,变的只有 tools_schema;
- 重建在**轮与轮之间**执行(不在工具批次中间)——REPL 的 `/reload` 天然满足;
- evals/子 agent 不受影响:它们不注册扩展。

## 4. 接线

- 启动时:`InteractiveSession(enable_extensions=True 默认)` 扫
  `extensions/*.py` 逐个注册(source=文件名),失败文件打警告继续
  (与技能发现"问题必须可见"同判据);`--no-extensions` 整层关;
- REPL:`/reload` 命令(走 §3 重建路径,横幅回显 ReloadReport);
- SDK:`InteractiveSession.reload_tools()` 公开方法供评测 B3 臂使用。

## 5. 门槛

| 编号 | 断言 |
| --- | --- |
| G-HR-1 | reload 后当轮生效:`get(name)` 返回新实例(替换实现验证) |
| G-HR-2 | 三失败场景:导入异常保留旧表 / 空 TOOLS 清理旧项 / 重名拒绝 |
| G-HR-3 | 会话内 reload:指纹重算不炸、历史保留、persist 钩子接到新 context |
| G-HR-4 | 启动加载:坏扩展警告继续、--no-extensions 全关 |
| G-HR-5 | ReloadReport 与内置重名拒绝扩展(DuplicateToolError) |

回归:pytest 全绿、mypy strict、契约 2/2;openai 路径与常驻区在**不 reload 时**
零字节变化(新功能不改既有路径纪律)。

## 6. 不拍的板

- 钩子表热重载何时做:等第一个真实钩子扩展出现;
- extensions 的发布形态(单文件 vs 目录包):等第二个扩展出现再定。
