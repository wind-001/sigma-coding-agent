## 2. 方案:按成本分三波,零成本先行

**排波的原则:能不花钱先不花钱;每一波单独可验收;花钱的行必须显式拍板预算。**

### 2.1 波 1:零 API 成本(不花钱,纯本地)

**a. 主张 4 → 缓存命中率报告行**

- 数据源:①既有全部会话的 JSONL(存量,`--timeline --json` 直接出 `cache_rate`);②一次对照实验:同一回放场景**开/关观测层各跑一遍**,证明采集零污染的同时给出确定性任务的命中率。
- 产出:`evals/reports/self_check.md` 增加"cache 命中率"行(DeepSeek 实测口径:cached/prompt,分"有压缩/无压缩"两列——压缩是否影响命中率本身就是 7.6 没敢写进表的问题)。
- 门槛 **G873**:`self_check` 报告的命中率行与从 JSONL 手算一致;注入=汇总只取最后一轮(复刻 2026-09-21 bug)变红。

**b. 主张 6 → 回滚成功率统计行**

- 方法:脚本驱动 `ShadowCheckpoint`(不经模型):构造 N=30 次写批次→随机破坏→回滚→逐文件比对 tree id。这是把现有 G66 族断言换成**统计口径**并落报告。
- 产出:`self_check.md` "回滚成功率 30/30(含删除文件场景)"。
- 门槛 **G874**:报告行由真实运行生成(不是写死的字符串);注入=比对函数只查文件数不查内容变红。

**c. 主张 7 → 对抗集拦截率/误拦率(走回放,零模型成本)**

- 关键判断:**C 类评的是闸(`CliApprovalGate`),不是模型**。用 `FakeProvider` 转录让"模型"发出危险调用,真实审批层在环,拦截行为完全真实——G103–G107 测试已是这个模式的单测版,本波把它参数化成 20 条对抗数据集(`datasets/adversarial/*.jsonl`)+ 10 条正常任务测误拦率。
- 产出:`self_check.md` "拦截率 20/20 · 误拦率 0/10"(7.5 口径,只进拦截指标、不进成功率)。
- 门槛 **G875**:①20 条对抗全部拦截(allowlist 未命中时);②10 条正常零误拦;③allowlist 命中的放行如实计入"免打扰次数"。注入=审批闸改为全放行变红。
- 诚实声明写进报告:回放口径测的是**闸的判定逻辑**;真实模型会不会真的发出这些调用是另一个问题,报告注明。

### 2.2 波 2:小成本(每行约 1–3 元 DeepSeek,须拍板预算)

**d. 主张 2 → 正式集 30 条 + aggregate 重跑**

- synthetic 12 → 30 条。**硬顺序不变:先写失败测试并验证它在当前代码上失败,再写任务描述**(R3 防自欺);20 条补量沿用 syn-001~010 的形态(单文件修复/多文件定位)。
- 跑法:30 条 × B1/B2 两档(B0 每条已跑过的不重跑;新增任务三档都跑)。
- 产出:`p1_gate3.md` 按正式口径重算(3/30 踩线、第 4 条红;Wilson 全过才达标)。
- 门槛 **G876**:30/30 任务 `--check-only` 三态复验通过;aggregate 报告重新生成且翻转方向标注正确。

**e. 主张 5 → 并发 vs 顺序(需要新开关)**

- `task_runner.py` 加 `--sequential`(档位名 `-seq`):传给 loop 一个"禁用只读并发"开关(实现:`ToolRegistry` 层加 `sequential_only`,或 loop 构造参数——实现期对齐,倾向 loop 参数,注册表语义不动)。
- 同一批任务 B2 与 B2-seq 各跑一遍,报告行=wall-clock 差 + 成功率不变。
- 门槛 **G877**:同任务 -seq 的 wall ≥ 并发版(只读并发无收益即设计失效);成功率两侧一致。

**f. 主张 8(steering 分支)→ 恢复率**

- 方法:脚本在回放中途注入一条**错误方向** steering(`FakeProvider` 转录 + `steering_drain` 回调),断言后续轮次采纳修正。回放可做,零成本——归入波 1 执行亦可。
- 门槛 **G878**:注入错误方向后,最终结果与不注入一致的场景 ≥ 预设清单。

### 2.3 波 3:结构性改动(后置,单独详规或并入收尾)

- **主张 1**(提示词 800 vs 5000):`build_system_prompt` 加 `verbose=True` 变体 + task_runner 档位 `-fat-prompt`。花钱。
- **主张 3**(树 vs 线性):SessionContext 加"无视父子关系、全量拼接"的对照模式。花钱。
- **主张 8**(B3 扩展):写一个最小扩展(如 ` forbid_suffix` 钩子)证明 B2→B3 行为改变。花钱少。
- 技能 token 差:离线算常驻区增量,零成本,可提前并入波 1 报告。
