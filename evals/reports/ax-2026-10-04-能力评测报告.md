# sigma agent 能力评测报告（ax 批次）

- 日期：2026-10-04
- 执行：task_runner.py（B0/B2 双档）× 20 题 × 各 1 次
- 模型：deepseek-chat（默认 preset。原计划路由智谱 GLM——与"转接到本会话同模型家族"的意向一致——但 SIGMA_API_KEY 实测 401 令牌过期，**该意向未能执行**，如实改用 deepseek）
- 成本：441,524 prompt + 20,594 completion tokens ≈ **¥0.48**（上限 ¥10，远未触顶）
- 数据集：`evals/datasets/synthetic/ax101..ax120`（本批新增，判据经**双向验证**：初始状态必失败 + 参考实现必通过；initial_failure 实测录制）

## 0. 一句话结论

**B2（完整 harness）20/20 全过；B0（无工具单轮）8/20。** 这证明在单元级任务上，harness 把大量"模型一次做不对"的任务变成了可解。但 20/20 同时意味着**这批题对 B2 没有区分度**——本轮真正的不足在评测覆盖面与题目难度，而不在通过率。详见 §4。

## 2. 纠错增益——agent 价值的直接证据

- 从零实现与多步编排两轴 **B0 全军覆没**（0/4）：没有工具闭环，模型一次写不对（看不到文件、跑不了验证）。这两类任务的完成完全依赖 harness。
- 6/20 任务出现工具失败（ax101/103/109/110/111/112，共 8 次），**全部被 agent 自行恢复**，没有一次因工具失败而放弃。
- 最"挣扎"的一题：ax110（目录归档，多步文件操作）用了 12 轮、3 次工具失败、68.6k prompt tokens 才完成——多步文件操作是本轮唯一出现明显反复的地方。

## 3. 效率

- B2 平均 ≈ 21k prompt + 1k completion/题，约为 B0 的 2.5 倍：harness 的正确性是用**上下文开销**换的（系统提示词 + 工具结果回灌）。对成本敏感场景需要权衡。
- 单题 wall-clock 4-20s（deepseek-chat，网络主导）。

## 4. 不足之处（本轮客观发现，按重要性排序）

1. **天花板效应：20/20 无区分度。** 缺陷修复与指令遵循两套 B0 就过了 3/4——这些题的描述信息量足够，单轮即可做对。要暴露 harness 的真实短板，需要 B0 全挂的难题（仓库级 bug、跨文件重构、模糊需求、长会话）。
2. **任务规模小。** 全部是单模块/单目录级任务，不能外推到大型仓库、多包协作、长执行链场景。
3. **单次采样，无方差信息。** 每题 N=1，通过率的置信区间不可知；严格结论需每题 N≥3。
4. **未测轴（覆盖面缺口）：** 联网检索与综合（web 工具未接入 task_runner——基建缺口）、长上下文与压缩、跨会话记忆、多 agent 协作、anthropic 协议、断点续跑。这些是 harness 的重要组成部分，本轮未给出数字。
5. **结论绑定模型。** 全部数字只对 deepseek-chat 成立；换模型结论可能完全不同（智谱 GLM 因 key 过期未能测）。
6. **评测器自身缺陷一次（已修复，如实记录）：** 首轮 B2 有 5 题被运行时产物污染判据误判——agent 按任务描述自验跑 pytest 必然产生 `.pytest_cache`/`__pycache__`，而文件集边界判据未一致地排除它们，导致 5 个功能全绿的运行被记为失败。修复（`judges.py` `_differs` 忽略运行时产物 + 边界判据过滤）后重跑，全部真实通过。这件事的教训：**评测器本身也需要被评测**，双向验证只保证了"判据对初始/参考态的行为"，没覆盖"agent 运行时副作用"这一态。
7. **工具失败率 30%（6/20 题、8 次）。** 全部恢复了，但摩擦真实存在；失败类型集中在文件操作与批处理脚本的中间态，值得看 transcript 归因。

## 5. 结论绑定条件（防止误读）

- 结论对 **deepseek-chat + 本 20 题 + 单次采样** 成立，不外推到其他模型、更大任务、真实生产工作流。
- B1（有工具、无 harness 干预）本轮未跑，"工具本身有用"与"harness 有用"的归因仍未分离——这是下一批最该补的对照。

## 6. 下一步建议（按性价比）

1. 出一批 B0 全挂的难任务（仓库级、跨文件、模糊需求）——不足之处会现形。
2. 补跑 B1 对照，完成 B0<B1<B2 归因链。
3. task_runner 加 `--web` 接入联网工具，补检索轴。
4. 修智谱 key 后加跑同题集，得到模型间对比。
5. 每题 N=3，给出方差与稳定性。
