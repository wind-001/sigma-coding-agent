## 技能说明
用于大模型长任务会话，清理冗余历史，削减无效 Token 消耗，防止旧日志、废弃方案干扰模型当前决策。
> 适用场景：多轮迭代开发、Agent 持续任务、长文档写作、复杂项目调试。

## 执行规则
### ✅ 需要保留信息清单
- 当前任务目标
- 已确认的关键决策
- 硬性核心约束（技术限制、需求边界、格式规范）
- 当前已完成进度
- 现存未解决问题
- 后续下一步行动

### ❌ 必须清理丢弃
- 失效、被推翻的旧方案
- 重复日志、调试碎信息
- 过时历史对话、已经解决的问题
- 无关发散讨论内容

## 输出要求
输出精简摘要，作为新一轮会话上下文；模型后续所有思考与执行，**仅基于这份摘要**，不再引用被清理掉的旧内容。

## 配套优化策略（Codex 长任务优化）
1. **利用 Prompt Cache**
固定不变内容（项目规范、AGENTS.md、系统角色、长期提示词）放在 Prompt 头部；动态变化的需求、临时信息放在末尾，提升缓存命中率，减少重复 Token 开销。
2. **定时触发 Compact**
长任务每隔若干轮对话主动调用本精简技能，避免上下文窗口持续膨胀。
